# Python Docker Model documentation

The repository overview, setup instructions, and development commands live in the [root README](../README.md).

The runnable Streamlit project is under [`Python/`](../Python/):

- [`Python/main.py`](../Python/main.py) is the Streamlit entry point.
- [`Python/src/`](../Python/src/) contains workflow, UI, and Docker Model Runner code.
- [`Python/tests/`](../Python/tests/) contains the automated test suite.
- [`Python/setup.bat`](../Python/setup.bat) creates or updates the local environment.
- [`Python/run.bat`](../Python/run.bat) starts one hidden Streamlit process and reuses it on subsequent runs.

Design and verification images are stored alongside this file.
